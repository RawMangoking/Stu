## 6. Registration Capacity Defect

The original registration validation used a strict greater-than comparison against course capacity. This allowed a registration attempt when the course was already full.

The condition was corrected to reject registration when the current enrollment is greater than or equal to the course capacity.

The boundary tests verify that:

- Registration is rejected when a course is full.
- Registration succeeds when exactly one seat remains.
- A rejected registration does not modify the student's registration or credit state, or the course enrollment count.

## 7. Course Withdrawal — Question Set E

The withdrawal feature allows a student to withdraw from a registered course.

The implementation:

1. Checks whether the student is registered in the course.
2. Removes the course from the student's registration set.
3. Deducts the course credits from the student's total.
4. Decreases the course enrollment when withdrawal succeeds.
5. Safely rejects withdrawal when the student is not registered.

The tests cover successful withdrawal, unsuccessful withdrawal, enrollment and credit updates, and another student registering in the seat released by withdrawal.

The `Course` enrollment decrement operation prevents enrollment from becoming negative.

### Deployment Commands

```powershell

```

Apply the manifests:




Kubernetes created a replacement Pod, restoring the desired replica count of three.
